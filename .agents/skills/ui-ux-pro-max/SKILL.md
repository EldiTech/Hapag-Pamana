# UI/UX Pro Max

AI-powered design intelligence with 79 UI styles, 192 color palettes, 74 font pairings, 119 UX guidelines, and 25 chart types across 22 tech stacks.

## What it is

A design reference skill that surfaces concrete UI/UX building blocks during design work: styles, palettes, typography pairings, UX guidelines, and chart types. It is intended to inform design decisions, not to generate full pages by itself.

## Coverage

- 79 UI styles
- 192 color palettes
- 74 font pairings
- 119 UX guidelines
- 25 chart types
- Across 22 tech stacks

## Supported platforms

Claude, Cursor, Windsurf, Copilot, Kiro, RooCode, KiloCode, Codex, Qoder, Gemini, Trae, OpenCode, Continue, Codebuddy, Droid, Warp, Augment, Antigravity, OpenClaw

## Install

```
npx ui-ux-pro-max-cli init --ai <platform>
```

Replace `<platform>` with the agent/runtime you are targeting (e.g. `claude`, `cursor`, `opencode`).

## When to use

- You are choosing a color palette and want options in the right vibe.
- You need a font pairing that works for a given UI style.
- You want UX guidelines for a component or pattern you are building.
- You are picking a chart type for a dashboard or data view.
- You want a UI style reference to keep a page/screen visually consistent.
