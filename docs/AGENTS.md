# Agent Instructions

## Git commit attribution

Do **not** add AI attribution to commits in this repository.

- No `Generated with Codebuff` / `Generated with ...` trailer.
- No `Co-Authored-By: Codebuff <noreply@codebuff.com>` or any other AI co-author line.
- End the commit message at its own last line.

Committing and pushing are still allowed and expected when asked. Only the attribution
trailers are removed — commit authorship stays with the human user's Git identity.

## Scope

Applies to every commit an agent creates here, including amend and squash operations.
